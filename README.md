Project Equitee was created by Jessy Lancaster and Mani Vinson as part of the re:power Data x Power 2023-2024 Fellowship. 

Project Equitee is a legislative voting scorecard and state dashboard focusing on anti and pro-trans legislation. 
By analyzing the 2023-2024 legislative sessions in Illinois and Ohio, we aim to provide invaluable perspectives from states situated at opposite ends of the trans-inclusive legislation spectrum within the Midwest.

You can view the project website and scorecards here: https://coda.io/@projectequitee/project-equitee-website
